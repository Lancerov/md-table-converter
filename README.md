# MD Table Converter

A lightweight Windows utility for converting tables between **Excel and Markdown**.

## Features

- Excel → Markdown
- Markdown → Excel
- Works through the clipboard
- Supports Unicode and Cyrillic
- Runs locally
- No installation, account or API key required

## How to use

1. Download and extract the project.
2. Run `Start Converter.cmd`.
3. Copy a table from Excel or paste a Markdown table into the app.
4. Choose the conversion direction.
5. Paste the result where you need it.

## Requirements

- Windows 10/11
- Windows PowerShell 5.1
